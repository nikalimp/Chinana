# Новостной контент-завод — Chinana

> Проект 2026-11-08 по запросу Ника. Статус: черновик, ждёт утверждения.
> Отдельный поток контент-завода рядом с SEO-блогом (20 статей в месяц): каждую неделю собирает новости вузов из каталога, отбирает важное для иностранных студентов и публикует на русском. Новость появляется в ленте `/news/` и на странице своего вуза.

## 1. Что получаем
- Лента `/news/` — новости вузов Китая на русском, с фильтром по вузу и теме.
- Блок «Новости вуза» на каждой странице `/universities/<slug>/` — 5 последних новостей этого вуза, ссылка «Все новости вуза».
- Страница новости `/news/<slug>/` — пересказ на русском, вуз, дата, ссылка на источник, CTA (поступление или консультация — по полю `partner` вуза).
- Свежий контент на страницах вузов — сигнал для поиска и нейросетей.

## 2. Схема

```
Вс 03:00 MSK  GitHub Actions: news-scan.yml
  universities.ts ─► newsSources ─► scripts/news-scan.mjs ─► content/factory/news/inbox/<дата>.json
  (RSS, страницы новостей)          (только заголовок, дата, ссылка, анонс)       коммит в main

Пн 11:11      Задача Claude «Контент-завод — новости вузов»
  inbox ─► фильтр по темам ─► отбор (лимиты) ─► пересказ на русском ─► check_post ─► content/news/*.md
                                                                                  ─► PR ─► автослияние ─► выкладка
```

Почему сбор в Actions, а не в сессии Claude: сайты вузов Китая доступны из GitHub Actions; у облачной сессии Claude сеть ограничена. Скрипт сбора детерминированный и дешёвый, Claude тратит время только на отбор и текст.

## 3. Источники
В `src/content/universities.ts` у каждого вуза — поле `newsSources[]`:

```ts
newsSources: [
  { type: "rss", url: "https://news.example.edu.cn/rss.xml", lang: "zh" },
  { type: "html", url: "https://iso.example.edu.cn/news/", lang: "en",
    item: "ul.news li", title: "a", link: "a@href", date: ".date" },
]
```

- Приоритет — разделы для иностранцев (International Students Office, 留学生, Admissions), затем общий раздел новостей вуза.
- Источники заполняются вместе с карточкой вуза. Нет ленты — `newsSources: []`, вуз в сборе не участвует.
- Скрипт хранит только метаданные: заголовок, дату, ссылку, анонс до 300 знаков. Полные тексты в репозиторий не кладём.
- Вежливость: 1 запрос в 2 секунды на домен, `User-Agent: ChinanaNewsBot (+https://chinana.ru/news/)`, уважение `robots.txt`.

## 4. Отбор
Темы (поле `topic` новости):

| Тема | Пример | Берём |
|---|---|---|
| `admission` | открыт набор, сроки подачи, новые программы для иностранцев | всегда |
| `scholarship` | гранты CSC, провинциальные, стипендии вуза | всегда |
| `exams` | CSCA, HSK, вступительные | всегда |
| `ranking` | рейтинги, аккредитации | да |
| `campus` | общежития, кампус, жизнь иностранных студентов | да |
| `science` | крупные научные новости | 1 в неделю на вуз, если значимо |
| остальное | внутренние события, партсобрания, спорт | нет |

Лимиты на неделю: до 2 новостей на вуз, до 30 новостей всего. Приоритет: вузы партнёра → темы `admission`, `scholarship`, `exams` → свежесть. Дубли (одна новость у нескольких вузов, например CSC) склеиваются в одну с несколькими вузами.

## 5. Текст новости — пересказ, не перевод
Новости вузов защищены авторским правом. Полный перевод — это производное произведение, для него нужно разрешение вуза. Поэтому:
- публикуем **пересказ своими словами** на русском, 150–400 слов: что произошло, что это значит для студента из России, что делать (сроки, ссылки);
- первый абзац — прямой ответ: «Нанкинский университет открыл набор на языковые курсы весна 2027: подача до 15 декабря»;
- цитата из источника — не больше одной и не длиннее 15 слов;
- ссылка на оригинал — обязательна, в конце: «Источник: сайт Нанкинского университета, <дата>»;
- фото с сайтов вузов не копируем: обложка — наша типографская (название вуза иероглифами + тема), делает инструмент `media` по брендбуку;
- факты, цифры, даты — только из источника; нет даты — не пишем дату;
- в тексте не обещаем поступление в вуз без партнёрства.

Это не юридическая консультация. Перед запуском потока стоит показать формат юристу по авторскому праву.

## 6. Формат файла
`content/news/<yyyy-mm-dd>-<slug>.md`:

```md
---
title: "Нанкинский университет открыл набор на языковые курсы — весна 2027"
description: "Подача до 15 декабря, старт в марте. Что нужно и как подать из России."
date: 2026-11-09
universities: [nanjing-university]
topic: admission
source:
  url: https://...
  title: "南京大学2027年春季汉语进修生招生简章"
  published: 2026-11-05
  lang: zh
cover: content/media/news/2026-11-09-nanjing-admission.png
---
```

Связь со страницей вуза — поле `universities[]`: страница `/universities/<slug>/` выбирает новости, где есть её slug. Один источник правды: список новостей вуза не пишется руками.

## 7. Сайт
- `/news/` — лента, фильтры по вузу и теме (весь список в HTML, фильтр — прогрессивно), пагинация по 20.
- `/news/<slug>/` — Schema `NewsArticle`: `about` → `CollegeOrUniversity` вуза, `isBasedOn` → ссылка на источник, `datePublished`.
- `/universities/<slug>/` — блок «Новости вуза» (5 последних) + `ItemList` в JSON-LD.
- `llms.txt` — раздел «Новости вузов» со ссылкой на ленту.
- Sitemap — все новости с `lastmod` = `date`.
- Telegram-канал Chinana — дайджест недели по понедельникам (5–7 главных новостей), через `site-channels`.

## 8. Задача по расписанию и контроль
- Новая общая задача контент-завода «Новости вузов» — понедельник 11:11, после воскресного сбора. Регламент — новый раздел в плагине content-factory (`references/news.md`), чтобы поток можно было подключить и другим проектам.
- Режим `approval` на первые 4 недели: PR с новостями ждёт Ника (метка `needs-nik`), потом — автослияние после `check_post.py` и `npm run check`.
- Пятничный отчёт завода получает раздел «Новости»: сколько собрано, отобрано, опубликовано, какие источники сломались (сайт поменял вёрстку → 0 новостей 2 недели подряд).
