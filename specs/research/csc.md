## Спорное и неподтверждённое

1. **Официальные порталы недоступны.** campuschina.org (ошибка 502), csc.edu.cn (ответ 412) и ru.china-embassy.gov.cn (доступ не получен) при проверке не открылись. Суммы стипендий (2500 / 3000 / 3500 юаней) подтверждены через порталы chinaservicesinfo (страница 2025 года) и CUG, а не напрямую через CSC. Перед публикацией сверить на campuschina.org.
2. **Компенсация за жильё.** По chinaservicesinfo — 700 юаней в месяц (бакалавриат, магистратура) и 1000 юаней (PhD). По МИСИС для российской квоты — 800–1000 юаней. На сайте указывать «по правилам вуза» или ссылаться на конкретный источник.
3. **Медицинская страховка.** 800 юаней в год взяты со страницы CUG без даты (в подвале сайта стоит 2002–2010). Для российской квоты МИСИС пишет «400–800 юаней» — это совпадает (400 юаней — для программ короче 6 месяцев). Условно подтверждено.
4. **Квота и сроки для России на 2027/2028** — не подтверждено. Квота 120 мест и сроки (24.11.2025 – 09.01.2026) — только для цикла 2026/2027.
5. **Подготовительный год.** Для российской квоты (Type A) — год языковой подготовки для всех программ (по МИСИС). Для Type B и программ на английском подготовки может не быть. Правило «бакалавры обязаны пройти подготовительный год» взято с портала Чунцина (2026); общее ли это правило для всех вузов, CSC напрямую не подтверждено.
6. **Обязательный CSCA для российской квоты.** Посольства (Индонезия, Канада) требуют CSCA от всех бакалавров по стипендии. Распространяется ли это на квоту Минобрнауки, прямого российского источника нет — по логике, да. Срок действия результата официально не назван; требование «дата сдачи после 1 марта 2025» косвенно говорит о сроке около двух лет. Не подтверждено.
7. **HSK для бакалавриата на китайском.** Посольство Индонезии на 2027/2028 указывает HSK 3 только для general scholar; Монреаль и CUG — для бакалавриата и general scholar. Возможно, это разница между странами или вариантами текста.
